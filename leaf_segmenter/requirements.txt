# ============================================================================
# requirements.txt — single environment for All_Models_CVPPP.ipynb
#
# That notebook runs all six models (SAM 2, Leaf Only SAM, HQ-SAM, Mask R-CNN,
# YOLO11-seg, Mask2Former) sequentially in ONE kernel, so it needs the union of
# the per-model requirements rather than the per-folder .venv split described in
# CLAUDE.md. Use the per-folder requirements.txt files when running the
# standalone run_*.py CLIs; use this file for the notebook.
#
#   python3 -m venv .venv
#   source .venv/bin/activate
#   pip install --upgrade pip
#   pip install -r requirements.txt
#
# Python 3.10+ (sam2's floor). 3.12 is fine — the old 3.10/3.11 ceiling in this
# file came from TensorFlow, which the notebook does not use.
#
# GPU: the default PyPI torch wheels are CUDA builds and work on WSL2. For a
# specific CUDA version install torch/torchvision first from
# https://pytorch.org/get-started/locally/ then run this file.
# ============================================================================
